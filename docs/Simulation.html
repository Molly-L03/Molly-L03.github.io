Permutation Test

Exploring the relation between physical activity and stress level
Author

Molly Liao

Published

November 5, 2026

Credit:

Laksika Tharmalingam created this dataset and is available on Kaggle, where I downloaded the CSV file.

Dataset Overview:

The Sleep Health and Lifestyle Dataset comprises 374 rows and 13 columns, covering a wide range of variables related to sleep and daily habits. It includes details such as gender, age, occupation, sleep duration, quality of sleep, physical activity level, stress levels, BMI category, blood pressure, heart rate, daily steps, and the presence or absence of sleep disorder. Each row represents a person.

In this permutation test, I will use columns:

  • Stress Level (scale: 1-10): A subjective rating of the stress level experienced by the person, ranging from 1 to 10.

  • Physical Activity Level (minutes/day): The number of minutes the person engages in physical activity daily.

Question of interest:

This semester, I started to work out more frequently and I found myself having a better mood and more energy whenever I hit the gym. Therefore, I want to explore whether people who do more physical activity have lower stress levels. In this test, we will first split up the dataset into high- or low-physical-activity groups. Then we will compare the average stress level of the two groups and use a permutation test to ask whether a difference that large could plausibly arise by chance if physical activity and stress were unrelated. We do this by repeatedly shuffling the stress scores across people, recording the difference in group averages each time, and checking where our observed difference falls in that distribution of shuffled differences.

The null hypothesis is that the stress level will be the same regardless of their daily physical activity. The alternative hypothesis is that more exercise leads to lower stress level.

library(ggplot2)
library(tidyverse)
health <- read_csv("Sleep_health_and_lifestyle_dataset.csv")

Based on the median and average minutes of physical activity, we will use 60 as a cutoff:

  • Equal or more than 60 minutes will be the “more” group.

  • Less than 60 minutes will be the “less” group.

Code 
#adding a column that indicates the group
health <- health |> 
    select(`Physical Activity Level`, `Stress Level`) |> 
    mutate(
        Exercise = if_else(`Physical Activity Level` >= 60, "more", "less")
    )

#calculate and show the observed statistics between 2 groups
health |> 
    group_by(Exercise) |> 
    summarize(
        num_people = n(),
        avg_stress = mean(`Stress Level`),
        avg_exercise_time = mean(`Physical Activity Level`),
        med_exercise_time = median(`Physical Activity Level`) 
    )

This boxplot visualized the self-rated stress level by exercise groups. The group that exercise less (than 60 minutes) had a higher stress level of median = 7, while those exercise more (than 60 minutes) reported a lower stress level (median = 5).

To simulate what we’d see if exercise has no relationship with stress, we first wrote a function, perm_health(), that performs one round of the simulation. If the null hypothesis is true, which group a person belongs to doesn’t matter, so randomly reassigning stress scores across people should produce differences in group averages that arise purely by chance.

In each round, the function (1) shuffles all the stress levels among the people in the data, (2) calculates the average stress level for the “more” and “less” exercise groups using both the original and the shuffled scores, and (3) returns the difference between those averages (more minus less) for both. (4) The argument rep isn’t used in the calculation. It labels which shuffle each result comes from.

Code 
#create a function that shuffles the stress level among all data and calculated the averages
perm_health <- function(rep, health){
    health |> 
        mutate(stress_perm = sample(`Stress Level`, replace = FALSE)) |> #(1)
        group_by(Exercise) |> 
        summarize( #(2)
            observe_avg = mean(`Stress Level`), #original score
            perm_avg = mean(stress_perm) #shuffled score
        ) |> 
        summarize( #(3)
            observe_avg_diff = diff(observe_avg),
            perm_avg_diff = diff(perm_avg),
            rep = rep #(4)
        )
}

One shuffle isn’t enough to tell us what chance looks like, so we use map() to run the function 1000 times, once for each number from 1 to 1000, passing the same dataset each time. list_rbind() stacks the 1000 results into one data frame, and set.seed() makes the shuffles reproducible, so the results don’t change each time the document is rendered.

Code 
#obtain the data with 1000-times shuffling
set.seed(1000) #fix the results of this shuffle
perm_stats <- map(c(1:1000), perm_health, health) |> 
    list_rbind()


perm_stats |> 
    ggplot(aes(x = perm_avg_diff))+
    geom_histogram(binwidth = .07)+
    geom_vline(aes(xintercept = observe_avg_diff, color = "Observed average difference \n-0.72"))+
    scale_color_manual(values = c("Observed average difference \n-0.72" = "red"))+
    labs(
        title = "Null sampling distribution (Average)",
        subtitle = "Bindwith = .07",
        x = "Permuted difference in average stress (more minus less)",
        y = "Number of shuffles"
    )

The histogram shows the 1000 permuted differences, which is the null distribution: the differences in average stress we’d expect from chance alone. The red line marks the difference actually observed in the data (-0.72), which is inconsistent with the null distribution.

The p-value is the probability of seeing a difference in average stress at least as extreme as ours, if exercise and stress are unrelated. Out of 1000 shuffles, none produced a difference as low as the observed -0.72, so the p-value is < 0.001.

Code 
perm_stats |>
  summarize(
    p_val_ave = mean(observe_avg_diff > perm_avg_diff))
# A tibble: 1 × 1
  p_val_ave
      <dbl>
1         0

Because this is well below the threshold (p < 0.05), we reject the null hypothesis. The data provide strong evidence that people in the more-exercise group have lower average stress than those in the less-exercise group, which is consistent with our alternative hypothesis. This matches the histogram above, where the observed difference falls far outside the range of differences produced by chance.

One thing to keep in mind is that, physical activity is just one of the factors that could contribute to stress level specifically in this dataset. There could be other factors such as sleep duration, nutrition, occupation, etc., affect stress levels.
